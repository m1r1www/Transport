# Справочник предприятий

Программа учёта предприятий на C++ с графическим интерфейсом (Windows Forms, C++/CLI). Позволяет хранить, просматривать, редактировать, сортировать и фильтровать данные о предприятиях. В комплекте есть мини-игра «Виселица» и исходники консольной версии программы.


## Возможности

- Добавление, редактирование и удаление записей о предприятиях
- Таблица записей (`DataGridView`) с двойным кликом для редактирования
- Сортировка по любому полю: через диалог или кликом по заголовку столбца (по возрастанию / убыванию)
- Панель «Поиск / Фильтр»
- Два режима работы: администратор (полный доступ) и обычный пользователь (только просмотр, поиск, сортировка)
- Автоматическое сохранение данных в текстовый файл при закрытии и загрузка при запуске
- Тестовые данные при первом запуске, если файла базы нет
- Мини-игра «Виселица» с окном правил «Как играть»
- Окно «О программе»

## Данные о предприятии

| Поле | Тип |
|------|-----|
| Название | строка (до 63 символов) |
| Год основания | целое число |
| Адрес | строка (до 63 символов) |
| Оборот (тыс.) | вещественное число |
| Количество сотрудников | целое число |
| Средняя зарплата | вещественное число |

## Формат файла базы

Данные хранятся в `database.txt` рядом с исполняемым файлом (UTF-8). Одна запись — одна строка с полями фиксированной ширины, разделёнными символом `|`:

```
[название:23]|[год:4]|[адрес:25]|[оборот:13]|[сотрудники:6]|[зарплата:11]|
```

Текстовые поля выравниваются по левому краю, числа — по правому.

## Сборка и запуск

Готовые `.exe` лежат в разделе **[Releases](../../releases)**. Чтобы собрать программы самостоятельно, нужны Windows и Visual Studio 2019/2022 с компонентом «Разработка классических приложений на C++» (для WinForms-версии также поддержка C++/CLI).

Склонируйте репозиторий:

```
git clone https://github.com/m1r1www/transport.git
cd transport
```

### Версия с графическим интерфейсом (WinForms)

**Через Visual Studio:** откройте `EnterpriseProject.sln`, выберите конфигурацию `Release` и нажмите **Ctrl+Shift+B** (сборка) или **F5** (сборка и запуск).

**Из командной строки:** откройте *Developer Command Prompt for VS* в папке с `.sln` и выполните:

```
msbuild EnterpriseProject.sln /p:Configuration=Release
```

Если msbuild попросит платформу, добавьте `/p:Platform=Win32` (или `x64`, в зависимости от настроек решения). Готовый `.exe` появится в папке `Release`.

При первом запуске рядом с `.exe` создаётся файл `database.txt` с тестовыми данными.
